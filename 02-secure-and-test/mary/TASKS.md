## Reflection (4–5 sentences)
The test `test_user_cannot_read_another_users_note` guards against **OWASP A01: Broken Access Control (Insecure Direct Object References - IDOR)**. It verifies that even when a user presents a valid authenticated session, they cannot read, modify, or leak records belonging to another account by tampering with resource IDs. If a teammate removed this check, authorization would degrade to simple authentication: any logged-in user would have unrestricted read access to everyone else's confidential notes across the entire platform. This demonstrates why authorization and object ownership verification must be enforced on every access to a keyed resource.
